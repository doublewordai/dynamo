G1 (active-block tracking for spillover deployments)

Context: this is Doubleword's Dynamo fork. The dw-spillover policy (lib/router-plugins/spillover) decides hosted-to-proxy failover from each hosted worker's estimated occupancy = router-tracked decode blocks / hosted_capacity_blocks. The router only tracks decode blocks when `router_track_active_blocks` is true. Production frontends run `--no-router-track-active-blocks`, so occupancy is always 0 and failover never fires. Turning tracking on frontend-wide would also change routing for every model that uses Dynamo's default policy, so we want it enabled only for spillover worker sets if the fork allows that. Read docs/spillover/PLAN.md.
