G1b (active-block tracking per spillover worker set, not frontend-wide)

Context: this is Doubleword's Dynamo fork. The dw-spillover policy needs router-tracked decode blocks (router_track_active_blocks) for the worker sets that serve spillover models, and it refuses to spill without them (lib/router-plugins/spillover/src/policy.rs). A frontend-wide flag would change routing for every other model. The frontend already supports a per-set override: a model card's `router_config` (lib/llm/src/discovery/watcher.rs, effective_router_config ~1408) replaces the frontend's router config for that worker set, and SGLang workers set it through their `--router-*` args (components/src/dynamo/sglang/args.py parse_worker_router_config, register.py build_router_config). The card checksum includes router_config (lib/llm/src/model_card.rs ~1297), so hosted SGLang workers and proxy workers must advertise identical values. The Rust proxy registers through lib/backend-common, which has no way to set a card router_config yet. Read docs/spillover/PLAN.md ("Active-block tracking").
